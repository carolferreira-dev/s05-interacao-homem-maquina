### Escolha o seu setup!

As atividades de programação em sala de aula deverão ser realizadas na plataforma **CodePen**, que permite criar, testar e compartilhar snippets de código HTML, CSS e JavaScript. Para os alunos que trarão o próprio notebook, há um tutorial para integrar o Visual Studio com o GitHub Pages, que facilita o gerenciamento de código e a visualização dos projetos na web.

### CodePen

O CodePen é uma plataforma online para desenvolver, testar e compartilhar trechos de código front-end (HTML, CSS e JavaScript). Permite criar projetos interativos direto no navegador, sem instalar nada. Serve como ambiente de prototipagem rápida, vitrine de portfólio e espaço colaborativo da comunidade de desenvolvimento web.

- Crie a sua conta em: https://codepen.io/

### Visual Studio e GitHub Pages

O **Visual Studio** é um ambiente de desenvolvimento integrado (IDE) da Microsoft para várias linguagens (C#, C++, Python, JavaScript etc.), com editor avançado, depuração, controle de versão, integração com banco de dados e ferramentas para web, desktop e mobile.

O **GitHub Pages** é um serviço gratuito do GitHub que hospeda sites estáticos direto de um repositório. É ideal para portfólios, documentação e projetos pessoais, com suporte a HTML, CSS, JavaScript e ao Jekyll (sites gerados a partir de Markdown). A publicação acompanha o versionamento do Git: cada alteração no repositório atualiza o site.

### Integração do Visual Studio com o GitHub

A integração é essencial para gerenciar o código durante as atividades do semestre: permite versionar o código, controlar alterações e manter um histórico claro das modificações.

**1. Instale o Git**
- Baixe e instale: https://git-scm.com/downloads
- Durante a instalação, mantenha as opções padrão.
- Documentação de primeiro uso: [Git - First-Time Git Setup](https://git-scm.com/book/en/v2/Getting-Started-First-Time-Git-Setup)

**2. Instale o Visual Studio (se ainda não tiver)**
- Baixe e instale: https://visualstudio.microsoft.com/
- Documentação de uso (controle de versão no VS Code): [code.visualstudio.com](https://code.visualstudio.com/docs/sourcecontrol/overview)

**3. Assista ao vídeo de configuração**
- Vídeo: https://www.youtube.com/watch?v=pabZgZf3R7g
- Não é necessário fazer a parte prática de código que vem depois da instalação e configuração.
