## Enunciado (Moodle)

Nesta atividade com Juliano Aleixo, vamos entender o valor da componentização de interfaces com React, para o desenvolvimento de aplicações web modernas e escaláveis. E exploraremos o conceito do ecossistema front-end ágil, utilizando ferramentas como Vite e Tailwind CSS, e entenderemos quais são as competências técnicas de implementação visual desenvolvidas na disciplina de Interação Homem-Máquina.
